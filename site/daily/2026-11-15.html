ForesightSafety-VLA: a safety benchmark for robot VLA models

RepoVLA & foundation modelstuotuoLyu/ForesightSafety-VLA

What it is. ForesightSafety-VLA is a simulation benchmark for safety-checking vision-language-action (VLA) robot policies, from the Brain-inspired Cognitive AI Lab at the Chinese Academy of Sciences. It is built on RoboTwin and is described in the authors' IROS 2026 paper. The repo ships 66 base scenarios (envs/safe_*.py) with hazards injected, constraints tightened, and time preconditions added, organized into a 13-category safety taxonomy covering physical interaction, language instructions, and visual perception.

Why it matters. Most VLA evaluations only ask "did the task succeed?" This one asks "did it succeed without breaking something?" A per-step dual-threshold monitor labels each episode as safe success, unsafe success, safe failure, or unsafe failure, and reports cumulative safety cost, risk exposure time, and a safety-adjusted success rate. One-factor sweeps over scene structure, language phrasing, and vision conditions show which input dimension degrades safety.

Can you try it without a robot? Partly. The scenarios are designed to run in the RoboTwin simulator, so a robot is not strictly required, but the README is thin on setup steps. You would need to install RoboTwin, run the safe_*.py evaluation scripts, and bring your own VLA model weights plus enough compute to run them. The repo does not appear to include weights. Also, the paper date and license need checking before you rely on it.

Try it without a robot: Install RoboTwin sim on your Mac, then run the safe_*.py eval scripts; expect friction on model weights/compute.
