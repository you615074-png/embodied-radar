Real2Worlds2Real: an agent that rebuilds real scenes as simulation

RepoWorld models & simreal2worlds2real/real2worlds2real

What it is: A code release (MIT license) for the paper Real2Worlds2Real: Scaling Self-Improving Agentic Real2Sim2Real for Robot Manipulation. The authors — Jinzhong Gu, Jiakai Chen, Xinyi Cao, Yan Shen, Hangke Sui and colleagues, affiliated with UC Berkeley, NVIDIA, UIUC and CMU — describe an agent called ASTRA that takes observations of a real scene and turns them into a simulated version. The agent picks layered skills and tools, inspects the evidence produced at each step, and revises its own results. One astra-e2e run can start from calibrated cameras and poses, use per-object workers, check physics, and assemble a scene.

Why it matters: Getting a real tabletop scene into a simulator is normally slow manual work — measuring objects, matching textures, tuning physics. If an agent can do most of that and catch its own mistakes, the loop "scan the real world, practice in sim, deploy back to real" gets cheaper. That loop is the core idea behind real2sim2real manipulation.

Can you try it without a robot? Only partly. The repo is a README with real-robot and simulation demo videos plus workflow docs. There are no visible training hyperparameters, datasets, or result tables, and the full pipeline expects calibrated real cameras and a real robot for validation. On a laptop you can read the agent workflow documentation and watch the demos, but you cannot reproduce the results. Note: the listed date and arXiv number also look questionable, so treat this as a concept read, not a runnable tool.

Try it without a robot: Watch the project page and sim demos first; the agent workflow docs are readable, but a full run needs calibrated cameras and a real robot — not on a Mac.
