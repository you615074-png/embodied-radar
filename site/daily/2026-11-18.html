Jevol-0.6B: a 0.6B VLA that flies a drone from one image and one sentence

ModelNavigation & drivingracineai/Jevol-0.6B

What it is: Jevol-0.6B is a small vision-language-action (VLA) model released on Hugging Face by Racine.ai. It takes one camera image (672×504) and one English sentence, and in a single forward pass picks three multiple-choice answers — forward/back speed with turn rate, vertical speed, and sideways motion — to form a flight command. It runs every 0.4 s. There is no memory, map, or past-decision record: each command comes only from what the camera sees now. Two larger siblings, Jevol-0.9B and Jevol-2B, are also released.

Why it matters: The authors report closed-loop flight results on a bench of eleven real places captured in 3D (places absent from training). A flight passes if the mission is completed without a collision. Per the model card, Jevol-0.6B passes 44.2% of flights, compared with 49.6% for Gemini 3.8 Flash (low thinking) and 45.9% for Claude Opus 5.5 (medium) on 135 flights each, while deciding in about 0.1 s versus seconds for the API models. The 0.6B model also runs in the browser via a Hugging Face Space, which is unusual for robotics models.

Can you try it without a robot? Yes, in a limited way. The Space lets you try the model on your own images from a browser. The authors also link a GitHub repository with code and a simulator, so you can run flights on a Mac in simulation — though per the card, training and full closed-loop evaluation likely need more compute than a laptop. The model card says the checkpoints carry no language-model head; a sentence head is used instead. Note that author/institution details are sparse, the license is 'other', and the release date shown is in the future — check before commercial use.

Try it without a robot: Try the HF Space in your browser first, then run the GitHub simulator locally on your Mac.
