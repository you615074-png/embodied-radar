PrimeSim: a multiview world-model simulator trained on 30k hours of robot demos

PaperWorld models & simPrimeSim: A Generalist World Model Simulator from Large-Scale Cross-Embodiment Demonstrations

What it is. PrimeSim, a paper from Travis Davies, Wentao Ma, Lihao Guo and colleagues, is an action-conditioned, multiview world model simulator. You give it a robot's commanded actions and a camera setup, and it generates video of what should happen next, from several views at once. The team started from a pretrained video generator, midtrained on 30,110 hours of robot demonstrations across 22 platforms, then posttrained it into an autoregressive simulator that runs at about 10.1 FPS.

Why it matters. A world model is only useful as a simulator if it obeys three rules: it follows the actions you command, it stays consistent between camera views, and it does not drift apart over long rollouts. The paper attacks each one: a unified cross-embodiment action representation with frame-aligned dual-path conditioning for action following, view-aware interleaved attention with explicit camera IDs for multiview consistency, and a "fast-video, slow-memory" posttraining scheme with hierarchical temporal memory to limit error accumulation. Per the paper, it stays stable on long-horizon rigid and deformable manipulation, adapts to held-out robot platforms in 100–200 gradient steps, leads four of five WorldSimProbe suites against five open-source action-conditioned world models, and its rollouts are good enough to run GRPO policy optimization on.

Can you try it without a robot? The model weights, inference code and training code are released, so you can read everything. Running it is another matter: video generation of this size is not realistic on a Mac with 16GB of unified memory and no NVIDIA GPU. Realistically you can follow the code, watch released rollouts, and treat it as a map of how modern world models are built.
