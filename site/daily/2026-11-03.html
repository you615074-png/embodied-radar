lerobot/pusht: A Classic Push-T Dataset for Learning Robot Imitation

DatasetManipulationlerobot/pusht

This is the lerobot/pusht dataset on Hugging Face — a converted version of the classic Push-T demonstration data from the Diffusion Policy paper by Cheng Chi, Zhenjia Xu, Siyuan Feng, Eric Cousineau, Yilun Du, Benjamin Burchfiel, Russ Tedrake, and Shuran Song. It contains 206 episodes (25,650 frames at 10 fps) of a simulated 2D robot pushing a T-shaped block. Each frame has a 96x96 image, a 2D state (end-effector position), and a 2D action.

Why it matters: it's one of the smallest and cleanest benchmarks for learning visuomotor policies from demonstration. You can train a behavior cloning model like Diffusion Policy or ACT end-to-end on a laptop and see the full pipeline — data loading, training, rollout, and evaluation — without owning a robot. The dataset is packaged in LeRobotDataset format (v2.0), so it plugs directly into Hugging Face's LeRobot library.

Can you try it without a robot? Yes. Install lerobot with pip, download the dataset via LeRobotDataset("lerobot/pusht"), and train a small policy on Apple Silicon. The environment is 2D simulation, and rendering a rollout only needs the recorded images or a lightweight simulator. It's not a new release — the underlying paper is from 2023 — but it remains a practical starting point for imitation learning beginners.

Try it without a robot: pip install lerobot, download this dataset, train Diffusion Policy or ACT behavior cloning on your Mac, then render rollouts to check.
