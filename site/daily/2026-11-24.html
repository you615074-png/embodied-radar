Motion Mamba 2.0: Long-Horizon Humanoid Control with Mamba

PaperHumanoids & leggedMotion Mamba 2.0: Autoregressive Diffusion Mamba for Long-Horizon Humanoid Control

Motion Mamba 2.0 is a paper from researchers at AIGeeksGroup (Yue Huang, Tianshan Zhang, Zeyu Zhang, Jayeon Kang, Akide Liu, Sungjoon Choi, Dacheng Tao, Hao Tang) that tackles long-horizon, real-time controllable motion generation for humanoid robots and interactive animation. The core idea is a Mamba-based root-body diffusion architecture that combines local attention, resumable recurrent states, and a persistent content memory (PCM) to keep track of distant history without the bounded caches of autoregressive diffusion. The authors also introduce an execution scheme using CUDA Graph replay and fused kernels to speed up inference.

Why it matters: long-horizon control is hard—robots need to remember what they did seconds ago while responding to new instructions. Per the paper, the method achieves accurate terminal control over rollouts up to 39.52 seconds on retargeted HiPHI, and reduces median latency from 1685 ms to 276 ms (6.1x speedup) on an RTX 4090, with real-world tests on a Unitree G1 humanoid.

Can you try it without a robot? The code is on GitHub, but it depends on CUDA and an RTX 4090. On a Mac you can't run the full pipeline. You could read the inference code to understand how Mamba states are reused, or watch the project page videos. No lightweight demo is provided.
