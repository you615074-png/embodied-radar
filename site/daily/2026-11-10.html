SmolVLA: A small Vision-Language-Action model you can train on one GPU

ModelVLA & foundation modelslerobot/smolvla_base

SmolVLA is a compact Vision-Language-Action (VLA) model released by Hugging Face as part of the LeRobot project. It takes multi-view images, robot proprioceptive state, and an optional language instruction as input, and outputs continuous actions. The model is trained with a flow matching objective and is intended as a base checkpoint to fine-tune on your own robot data.

Why it matters: most VLA models are large and expensive to train. SmolVLA is designed to be trainable on a single consumer GPU and deployable on affordable hardware, while per the paper aiming to match the performance of much larger VLAs through community-collected data. The weights, code, and example datasets are all open (Apache-2.0), which makes it a practical entry point for learning imitation learning and VLA architectures.

Can you try it without a robot? Partly. You can install lerobot[smolvla], load the lerobot/smolvla_base checkpoint, and run select_action on frames from a dataset like lerobot/libero to see predicted actions. Full fine-tuning needs a CUDA GPU, but inference on CPU or Apple Silicon is possible for small batches. The README includes a complete quick-start snippet and training commands.

Try it without a robot: pip install lerobot[smolvla], load the model on Mac and run select_action on the LIBERO dataset; fine-tuning needs a cloud GPU
