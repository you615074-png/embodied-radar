MABEL: An Open-Source Mobile Bimanual Robot with a Sim-First Workflow

RepoHardwarerobotmabel/open_mabel

MABEL is an open-source mobile bimanual robot from the robotmabel project: a three-module swerve base, a vertical lift, a pitching torso, a 3-DOF active head with stereo cameras, two 7-DOF arms (OpenArm-derived), and two 17-DOF anthropomorphic hands (ORCA-derived) — 56 degrees of freedom in total. It can be teleoperated whole-body from a single Apple Vision Pro without hand-held controllers.

The repository is organized as a step-by-step guide: simulate, teleoperate, collect data, train a policy, build the hardware, and bring up the real robot. It includes CAD and a bill of materials, PCB sources, firmware, a HAL, a control library, a ROS 2 Jazzy workspace, a canonical MuJoCo model with 30 scenes, browser-based control studios, and an imitation learning pipeline that goes through data curation, LeRobot, and ACT/DP/π0.

Why it matters: full-stack open robot projects are still rare, and this one treats simulation as the first-class entry point rather than an afterthought. You can follow the whole software story before spending money on parts.

Can you try it without a robot? Partly. Steps 1–5 need no hardware: you can install the controller library, run bash server/run.sh to launch the MuJoCo simulation, and view the robot in a browser. Training a policy and running RL need a CUDA GPU, so a 16GB Mac can simulate but not train. Vision Pro teleoperation needs the headset. There is no paper or third-party validation yet, and the star count is low, so treat it as a learning map rather than a proven platform.

Try it without a robot: Install MuJoCo on Mac, run server/run.sh to drive the simulated robot in browser; policy training needs an NVIDIA GPU.
