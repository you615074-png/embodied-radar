Alloy: a multi-material physics engine that runs on your Mac

RepoWorld models & simargonrobotics-ai/alloy

What it is: Alloy is an open-source (Apache-2.0) physics engine for robot learning from Argon Robotics. It is built on Newton, MuJoCo Warp and Warp, and it puts rigid robots, cloth, soft bodies, liquids and granular material in the same scene. Each object is described once as a YAML card, and a router sends it to the right solver: MuJoCo Warp for rigid bodies, VBD for cloth, MPM for sand, and Alloy's own DFSPH for liquids.

Why it matters: Most robot-learning sims are good at rigid bodies and awkward with fluids or cloth. Alloy aims to let one scene contain a robot arm pouring water, folding a towel, or dragging a cable through sand. It also runs in parallel worlds — thousands for free rigid bodies, up to 4,096 for a robot arm on one GPU — which is the kind of throughput RL wants. There is also an alloy mcp server, so an AI agent can build and step scenes as tools.

Can you try it without a robot? Yes, on a Mac with Apple silicon. pip install alloy-engine inside a Python 3.11/3.12 virtual environment, then run the ready-made Pour-v0 (move a bowl under a stream) or ClothFold-v0 (experimental). No NVIDIA GPU means CPU only and slow stepping, and this is an early 0.x release, so expect API changes.
