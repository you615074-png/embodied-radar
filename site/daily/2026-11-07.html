Embodied Agent Arena: Can Frontier VLMs Be Robot Generalists?

PaperVLA & foundation modelsAre Frontier VLM Agents Ready to Be Robot Generalists? An Empirical Study with the Embodied Agent Arena

What it is. A paper from Haojian Huang, Pukun Zhao, Zexi Li and colleagues introducing Embodied Agent Arena, a benchmark for asking a blunt question: can today's best vision-language models act as general-purpose robot agents? The Arena collects 1,000 test cases across five areas — geometry, spatial reasoning, affordance, task planning, and manipulation. 32 existing sources are combined with GeoProbe, the authors' own 168-case set for camera, motion, depth and scale estimation. A deliberately minimal harness hands task decisions to the model through each source's native interface. Ten VLM agents were evaluated.

Why it matters. Closed-weight models lead in all five domains. Open-weight VLMs do show useful spatial reasoning, but their planning and manipulation success is much lower. The more interesting part is the failure analysis. Models that look equally wrong on geometry can be failing for different reasons — one distorted by scale, another by shape. Estimating a valid region does not mean the model can pick a usable action point. Agents hit early subgoals, then lose control of the object, attach an action to the wrong receiving region, or stop before the required physical state is reached. More compute does not fix this evenly: code repair can restore execution without finishing the task, and self-review can flip a correct judgment into a wrong one.

Can you try it without a robot? Partly. The evaluation is API-based, so a laptop can call models on Arena items. Whether a runnable harness is actually released is not clear from the abstract — check the repository before planning anything around it.
